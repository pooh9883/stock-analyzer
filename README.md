# AI Stock Analyzer (ฟรีตลอด) — คู่มือติดตั้ง

## ขั้นที่ 1: ติดตั้ง Python (ถ้ายังไม่มี)
ดาวน์โหลดจาก https://www.python.org/downloads/ (เลือกเวอร์ชัน 3.10 ขึ้นไป)
ตอนติดตั้งบน Windows ให้ติ๊ก "Add Python to PATH" ด้วย

## ขั้นที่ 2: ติดตั้งไลบรารีที่ต้องใช้
เปิด Terminal / Command Prompt แล้วไปที่โฟลเดอร์นี้ จากนั้นรัน:

```
pip install -r requirements.txt
```

รอจนติดตั้งเสร็จ (ใช้เวลาประมาณ 1-2 นาที)

## ขั้นที่ 3: รันแอป
ยังอยู่ในโฟลเดอร์เดิม รันคำสั่ง:

```
streamlit run app.py
```

เบราว์เซอร์จะเปิดขึ้นมาเองที่ http://localhost:8501

## ขั้นที่ 4 (ไม่บังคับ): ขอ Gemini API Key ฟรี สำหรับปุ่ม "ขอ AI สรุปเพิ่ม"
1. ไปที่ https://aistudio.google.com/app/apikey
2. ล็อกอินด้วย Google Account
3. กด "Create API Key" — ไม่ต้องผูกบัตรเครดิตสำหรับ free tier
4. คัดลอกคีย์ (ขึ้นต้นด้วย AIza...)
5. เอาไปใส่ในช่อง "Gemini API Key" ที่แถบด้านซ้ายของแอป

**ถ้าไม่ใส่ก็ใช้แอปได้ปกติ** เพราะคะแนน 10 มิติหลักไม่ต้องพึ่ง Gemini เลย

## วิธีใช้งาน
1. พิมพ์ชื่อหุ้น (ticker) เช่น NVDA, SNDK, AAPL ที่แถบซ้าย
2. กด "🚀 วิเคราะห์หุ้น"
3. ดูคะแนน 10 มิติที่คำนวณอัตโนมัติ พร้อมคำอธิบายเหตุผล
4. กดลิงก์ด้านบน เพื่อเปิดไปดู Google Trends / Unusual Whales / Quiver / AltIndex ของหุ้นนั้นๆ ต่อ
5. ถ้าอยากได้สรุปแบบข้อความอ่านง่าย กด "✨ ขอ AI สรุปเพิ่ม" (ต้องใส่ Gemini key)

## เรื่องความแม่นยำที่ต้องรู้
- ข้อมูลราคา/งบการเงินจาก yfinance อาจดีเลย์ 15-20 นาที ไม่ใช่ real-time
- คะแนน 10 มิติคำนวณจากสูตรตายตัว (P/E, ROE, Debt/Equity ฯลฯ) ไม่ใช่ AI ตัดสินใจ
  → แม่นยำและตรวจสอบได้ทุกจุด แต่ไม่ได้ "ฉลาด" แบบเข้าใจบริบทธุรกิจลึกๆ
- ควรใช้เป็นจุดเริ่มต้นคัดกรอง ไม่ใช่คำแนะนำซื้อ-ขายขั้นสุดท้าย

## เผยแพร่ขึ้นเว็บฟรี (ไม่บังคับ)
ถ้าอยากเปิดแอปนี้จากมือถือได้โดยไม่ต้องเปิดคอมทิ้งไว้:
1. อัปโหลดโค้ดขึ้น GitHub (สร้าง repo ฟรี)
2. ไปที่ https://streamlit.io/cloud → เชื่อมต่อกับ GitHub repo
3. Deploy ฟรี — จะได้ลิงก์ให้เข้าจากที่ไหนก็ได้
   (Gemini API Key ให้ใส่ผ่าน Streamlit "Secrets" แทนการพิมพ์ในแอปทุกครั้ง)
